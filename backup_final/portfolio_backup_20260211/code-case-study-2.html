Venue Capacity Optimization

Python Analysis Code with Annotations

📊 Business Question

Are events right-sized? Which venues consistently sell out (need bigger spaces) vs. struggle to fill seats?

🎯 Key Finding

312 events consistently selling out (>95%) represent £184K potential revenue uplift by moving to larger venue tiers. 89 events with <50% capacity are wasting 3,400+ empty seats.
