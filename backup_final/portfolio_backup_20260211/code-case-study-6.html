Spotify Global Expansion Strategy

Multi-Criteria Decision Analysis (MCDA)

📊 Business Question

Which international markets should Spotify prioritize for expansion to maximize growth potential and minimize competitive risk?

🎯 Recommendation

Indonesia ranked #1 (weighted score: 8.7/10) due to massive untapped market (275M population, 71% mobile penetration, low streaming adoption). India and Brazil follow as tier-1 opportunities.

Methodology: Multi-Criteria Decision Analysis Python 
# MCDA Scoring Framework
import pandas as pd
import numpy as np

criteria = {
    'market_size': {'weight': 0.30, 'direction': 'max'},
    'smartphone_penetration': {'weight': 0.25, 'direction': 'max'},
    'gdp_per_capita': {'weight': 0.20, 'direction': 'max'},
    'competitive_intensity': {'weight': 0.15, 'direction': 'min'},
    'regulatory_ease': {'weight': 0.10, 'direction': 'max'}
}

# Normalize scores 0-10, apply weights, aggregate
scores['weighted_score'] = sum(
    scores[criterion] * details['weight'] 
    for criterion, details in criteria.items()
)

💡 Analysis Framework

  1. Market Sizing (30%): Population × Mobile penetration × Willingness to pay
  2. Infrastructure (25%): Smartphone adoption, 4G coverage, payment systems
  3. Economic Viability (20%): GDP per capita, disposable income trends
  4. Competitive Landscape (15%): Incumbent market share, barriers to entry
  5. Regulatory Environment (10%): Licensing ease, content restrictions, data laws
