Geographic Demand Heatmap Analysis

Python Analysis Code with Annotations

📊 Business Question

Where is demand outpacing supply? Which cities offer the highest expansion potential based on unmet search volume?

🎯 Key Finding

Birmingham shows the highest unmet demand with a 22.1× search-to-event ratio (17% above platform average). This represents a £127K annual revenue opportunity if supply is normalized.

01_geographic_demand.py Python 
# Geographic Demand Analysis
import pandas as pd

# Calculate demand (searches) vs supply (events) by city
demand_supply['ratio'] = demand_supply['searches'] / demand_supply['events']

# Identify gaps relative to platform average
platform_avg = demand_supply['searches'].sum() / demand_supply['events'].sum()
demand_supply['gap_score'] = (
    demand_supply['searches'] - 
    (demand_supply['events'] * platform_avg)
)

# Output: Birmingham (22.1x) > London (17.6x) > Manchester (16.2x)

💡 Methodology

  1. Ratio Analysis: Normalized search volume by available inventory to identify true scarcity vs. just high volume.
  2. Gap Scoring: Quantified the "missing" events needed to meet demand, prioritizing cities with both high ratios and absolute volume.
  3. Genre-Level Drilldown: Validated that the gap was structural across multiple genres (Techno, House), not just a single niche.
