Churn Prediction Model

Classification Model for User Retention

📊 Business Question

Which users are at risk of churning? Build a predictive model to enable targeted retention campaigns.

🎯 Model Performance

Logistic Regression classifier achieved 87.3% ROC-AUC score. Top churn indicators: 30+ days since last purchase (42% importance), declined email engagement (28%), and reduced search activity (19%).
