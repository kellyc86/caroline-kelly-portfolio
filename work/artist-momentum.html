Which artists are gaining momentum this week?

A weekly music intelligence platform for an A&R use case: it monitors artists across Spotify, Instagram, 16 music publications and official charts, then delivers a Monday email digest and a live dashboard.

RoleSole builder, individual coursework
StackPython, spotipy, instaloader, feedparser, Playwright, SQLite, DuckDB, Parquet, FastAPI, SendGrid, Jinja2, Docker, GitHub Actions
StatusVersion 1 prototype; 15 API endpoints, weekly schedule designed but not yet activated
CodeView on GitHub ↗
Independent coursework built around a UMG-style brief. Not commissioned by Universal Music Group.

Problem

An A&R team needs to know which artists are moving, but the signals sit on separate platforms: follower counts, chart entries, press coverage and social engagement. Any single source is biased towards whichever platform an artist is strong on.

The pipeline combines them into one weighted momentum score, detecting chart new entrants as they first appear and surfacing a discovery pool of new artists.

Skills

  • Ingestion: Spotify Web API, Instagram public profiles, 16 press RSS feeds with NER entity extraction, Apple Music and Billboard charts via headless Chromium
  • Storage: append-only SQLite staging, every row timestamped, then DuckDB and Parquet weekly snapshots
  • Scoring: cross-source momentum with different weights for a subscriber pool and a 500-artist discovery pool
  • Event time: articles filtered by published_at, not fetched_at, with 14-day recency weighting
  • Delivery: FastAPI backend, SendGrid Jinja2 digests, static dashboard with a demo mode
  • Resilience: every external call wrapped so one source failing never crashes the pipeline

Results

5data sources merged into one weekly momentum score
16music publications ingested, weighted by source tier and recency
15API endpoints serving the digest and dashboard

Pipeline

1 · ChartsApple Music UK and US, Billboard Hot 100; new entrants flagged on first appearance.
2 · PlatformsSpotify followers and popularity; Instagram followers and engagement.
3 · Press16 RSS feeds, named-entity extraction, false-positive filtering.
4 · StagingSQLite, append-only, nothing overwritten.
5 · ScoreSpotify velocity, Instagram, press and chart bonus; bands from monitoring to breakout.
6 · DeliverMonday digest by email and a FastAPI dashboard.
Limits. Spotify's Development Mode strips follower counts and popularity scores, so Spotify velocity is effectively zero for most artists, and Instagram's rate limiting means some weeks the data is unavailable. The first rendered digest shows this plainly: every artist at momentum 20.0 and all 100 Billboard rows flagged as new entries. Momentum scores measure current weekly activity only, not predictions. No test suite yet.
