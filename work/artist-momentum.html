Which artists are gaining momentum this week?

A weekly music intelligence platform for an A&R use case: it monitors artists across Spotify, Instagram, 16 music publications and official charts, then delivers a Monday email digest and a live dashboard.

RoleSole builder, individual coursework
StackPython, spotipy, instaloader, feedparser, Playwright, SQLite, DuckDB, Parquet, FastAPI, SendGrid, Jinja2, Docker, GitHub Actions
StatusVersion 1 prototype; 15 API endpoints, weekly schedule designed but not yet activated
CodeView on GitHub ↗
Independent coursework built around a UMG-style brief. Not commissioned by Universal Music Group.

Problem

An A&R team needs to know which artists are moving, but each source favours whichever platform an artist is strong on.

The pipeline combines four sources into one weekly score per artist (Spotify velocity 60%, Instagram 30%, press 10%; press 50% for a discovery pool) and sends a Monday digest. The score is version one, and the first run showed why.

Skills

  • Ingestion: Spotify Web API, Instagram, 16 press RSS feeds with NER, Apple Music and Billboard charts via Playwright
  • Storage: append-only SQLite staging, DuckDB and Parquet weekly snapshots
  • Scoring: separate weights for subscriber and 500-artist discovery pools
  • Event time: articles filtered by published_at, not fetched_at
  • Delivery: FastAPI, SendGrid digests, static dashboard with demo mode
  • Resilience: every external call wrapped; one source failing never crashes the run

Results

20.0momentum for all ten artists in the first digest (4 April 2026): one Spotify snapshot gives 0.0% growth, normalised to 33.3 and weighted at 60%, so everyone scores the same
100 of 100Billboard rows flagged as new entries: no prior week stored, so everything is a first appearance
3of 16 publications carried a tracked artist's album announcement; the press feed caught it but at 10% weight the score did not move

Pipeline

1 · ChartsApple Music UK, US; Billboard Hot 100.
2 · PlatformsSpotify followers, popularity; Instagram engagement.
3 · Press16 RSS feeds, entity extraction.
4 · StagingSQLite, append-only.
5 · ScoreWeighted signals, chart bonus, three bands.
6 · DeliverMonday email digest and dashboard.

What a label would do with this

Release-week measurement: run it the Monday after a Friday release and compare an artist's follower velocity, press count and chart entry against their own previous weeks, not the roster. The press-weighted discovery pool is a shortlist for A&R to check before the charts confirm it.

Limits. Spotify's Development Mode strips follower counts and popularity, so velocity is effectively zero; Instagram rate limiting left no Instagram data in the first digest. Fixes: a second weekly snapshot so velocity is a real difference, Spotify Extended Quota Mode for live counts, and the popularity-score fallback now in the code. Scores measure current activity, not predictions. No tests yet.
