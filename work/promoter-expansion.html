Where should an independent promoter expand next?

A single-page map dashboard that scores 21 UK cities for an indie and alternative live-music promoter, combining venue data, student population, market gap, cultural fit and distance from London into one ranked view.

RoleIndividual, self-directed
StackHTML, vanilla JavaScript, Leaflet 1.9.4, MusicBrainz API
Statusv1.0 first draft, working concept
Codegithub.com/kellyc86/FormProjectExample
Independent work. I am not affiliated with the promoter analysed and this was not commissioned; it is a v1 concept built to show how the question could be framed. One of the five weights, cultural fit, is hand-calibrated rather than derived from data.

Problem

An independent promoter with a strong London base has more options for a second city than it can research properly. Which cities have the venues, the audience and the room in the market to support an indie and alternative programme, and how far are they from the existing operation?

The aim was a tool that put the whole shortlist on one screen and made the trade-offs visible without opening a spreadsheet.

Skills

  • Scoring model: five weighted factors, venue density 20%, student population 25%, market gap 30%, cultural fit 15%, distance from London 10%
  • Live data: venue counts pulled from the MusicBrainz API on page load
  • Open data: student population from HESA 2022/23
  • Front end: one index.html of roughly 600 lines, plain JavaScript with Leaflet for the map
  • Narrative: per-city deep-dive covering venues, comparable artists and risks

Results

21UK cities scored and ranked on one screen
5weighted factors, with the weighting shown beside the map
30%largest weight, market gap; change it and the order changes for visible reasons

The weighting

The value is less in any single ranking than in making the weighting explicit and showing where a judgement call is doing the work.

Limits. The AI brief button does not work as shipped: it calls the Claude API directly from the browser with no key, so it shows "API unavailable". The MusicBrainz fetch takes around 23 seconds on load. City data is hard-coded, there is no README and no data files, and the cultural-fit weight is my own judgement rather than something measured.
