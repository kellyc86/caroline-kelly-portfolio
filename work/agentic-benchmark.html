Does a high rubric score mean a good model?

Three coding agents were set the same four data-science tasks on NYC Airbnb listings and marked against a shared rubric. The tool with the best rubric total shipped the worst baseline.

RoleGroup of five. I operated the Antigravity agent across all four tasks and confirmed the dataset schema
StackPython, scikit-learn, Git, Antigravity, Claude, Codex
DataNYC Airbnb Open Data 2019: 48,895 listings, 16 features, nightly price as target
CodeView on GitHub ↗
Group project. The repository is hosted by a group member; the Antigravity branch and its task outputs are my work. Other members ran the Claude and Codex agents and carried out the reviews.

Problem

Which tool produces the most accurate, reproducible and well-documented outputs on standardised pipeline tasks, and do rubric compliance and model quality point in the same direction?

Price is heavily right-skewed (mean $152, median $106). No agent was given guidance on target transformation, making the log transform a test of statistical judgement rather than instruction following.

Skills

  • Benchmark design: four sequential tasks, shared evaluate.py rubric with four automated and one manual check per task
  • Reproducibility controls: SEED=42 in every split, relative paths, Git branch isolation per agent
  • Agent operation: ran Antigravity end to end, Task 01 scored 5/5 in 15 minutes
  • Leakage discipline: log1p target and scikit-learn Pipelines so scalers and encoders fit on training data only
  • Human review: manual inspection of notebook cell order for leakage boundaries

Results

19/20Codex's rubric total, the highest of the three
−0.625Codex's baseline R², worse than predicting the mean, reported silently with no error raised
0failures self-detected by an agent; every one was found by a human reviewer

Rubric against model quality

Rubric totals were Antigravity 18/20, Claude 16/20 and Codex 19/20. Improved test RMSE and R² were 106.07 and 0.352, 74.87 and 0.485, and 86.53 and 0.463. Claude scored only 2/5 on Task 01 and produced the strongest model; Antigravity completed each task fastest at 25 minutes on average.

01 IngestionZero nulls, every imputation documented
02 EDATraining data only, written interpretations
03 BaselinePreprocessing fitted on training data only
04 ImprovementAbove 1 per cent, rejected approaches recorded
Limits. Rubric-based scoring measures process compliance: files present, schemas valid, SEED documented. It does not measure whether the model is statistically sound. Codex's 42.53 per cent RMSE improvement reflects recovery from a broken baseline, not advancement. Each tool had a different operator, so prompting style is confounded with the tool.
